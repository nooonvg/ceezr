# CAP-RUN-20261016 — بيئة السعة والموثوقية المعزولة

بيئة تشغيل حمل حقيقي على بوابة وعامل حقيقيين، بلا أي وصول للإنترنت، ومحاكي تيليجرام مستقل يسجّل كل رسالة.

## العزل (على مستوى الشبكة لا متغيّرات البيئة)
- كل العمليات (PostgreSQL، Redis، البوابة، المحاكي، المولّد، المراقب، منسّق الأعطال) تعمل داخل network namespace اسمه `ceezrsbx` فيه `lo` فقط ولا مسارات. نداء `api.telegram.org` أو أي IP خارجي يفشل على مستوى الشبكة (مختبر: `tests/edge.ts` E4).
- `mocks/telegram-egress-guard.ts` (preload) يحوّل نداءات Telegram إلى المحاكي ويرفض أي مضيف غير loopback ويسجّله في `egress-blocked.jsonl`، ويخرج بالرمز 78 إن لم يكن عنوان المحاكي loopback (fail-closed).
- `svc.sh assert` يرفض البدء ما لم تكن القاعدة على `127.0.0.1:55432` بمجلد بيانات `/srv/ceezr-cap-20261016/pg` وعلامة GUC `ceezr.run_marker`، وRedis على `56379` بمجلد الجولة، والـnetns بلا واجهات غير lo.
- لا `FLUSHALL` ولا `TRUNCATE` ولا حذف في أي سكربت هنا.

## المكوّنات
| ملف | الدور |
|---|---|
| `svc.sh` | تشغيل/إيقاف الخدمات داخل الـnetns وتأكيد العزل؛ `CODE_DIR` لتشغيل نسخة كود أخرى (مثل PR #558) |
| `config/run.env` | إعدادات الجولة (لا أسرار؛ الأسرار في `/srv/ceezr-cap-20261016/secrets.env` بصلاحية 600 ولا تُطبع) |
| `config/seed-cities.sql` | تفعيل 5 مدن ومعرّفات قروبات وهمية |
| `mocks/telegram-mock-server.ts` | محاكي Bot API: يسجّل كل نداء، حدود 30/ث لكل بوت (429 صلب)، 1/ث لكل محادثة و20/د للقروب (مخالفات تُعدّ) |
| `load/capacity.ts` | المولّد: 1000 سائق و1000 زبون عبر حوار البوت الحقيقي؛ السائق يتصرف فقط على العروض التي وصلت صندوقه في المحاكي |
| `monitor/monitor.ts` | مقاييس كل 10ث وتقارير الدقائق 10..60 تُكتب على القرص تلقائيًا |
| `monitor/chaos.ts` | أعطال: قتل اتصالات PG، أقفال، إعادة تشغيل PG، إيقاف/إعادة Redis، قتل البوابة (kill -9) وإعادتها، قتل shim |
| `monitor/analyze.ts` | أرقام الجولة من القاعدة والمحاكي مباشرة → `round-metrics.json` |
| `tests/edge.ts` | مصفوفة الحالات الحدية على النظام الحي → `edge-cases.json` |
| `run-round.sh` | جولة كاملة في مجلد فريد |

## تشغيل جولة
```bash
ROUND=r03-soak60 CHAOS=1 PROFILE='[{"name":"base","sec":300,"conc":50}, ...]' setsid bash run-round.sh
```
الزمن الصفري للجولة = حدث `load.start` بعد التهيئة وتفريغ طابور الوارد؛ البذر والبناء لا يُحسبان.
