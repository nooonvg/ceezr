# بيئةُ الحملِ التجريبيّة — `SANDBOX-SOAK-01`

تشغيلُ **البوّابةِ الحقيقيّة** (`apps/gateway/src/index.ts` بوضعِ الإنتاج، والعاملُ مدمجٌ بكلِّ وظائفِه) على
بنيةٍ محلّيّةٍ كاملة، ثمّ ضغطُها بطلباتٍ وهميّةٍ للمشاويرِ والتوصيلِ وقروباتِ السائقين.
**لا يلمسُ الإنتاج**: لا Supabase ولا Render ولا تيليجرام حقيقيّ (`AGENTS.md`: لا تغييرَ لبياناتِ الإنتاجِ للاختبار).

## المكوّنات

| المكوّن | المصدر |
|---|---|
| PostgreSQL 18 + PostGIS، قاعدةُ `waslah_test` (UTF-8) | `supabase/migrations` عبرَ `scripts/migrate.ts` |
| Redis + Upstash REST shim (:8081) | `docker/upstash-rest-shim` |
| البوّابة (:4300) | `config/sandbox.env`: أسرارٌ وهميّة، `PROCESS_TOPOLOGY=single-process`، `RUN_WORKER_IN_GATEWAY=true` |
| محاكي تيليجرام | `mocks/telegram-mock-preload.ts` يُحمَّلُ بـ`bun --preload`، يعترضُ `api.telegram.org` ويردُّ بصيغةِ Bot API ويسجّلُ كلَّ رسالة. **حدودُ المعدّلِ الحقيقيّةُ تبقى سارية** (المُرسِلُ لا يعلمُ أنّه محاكى) |
| مولّدُ الحمل | `load/soak.ts` يُرسلُ تحديثاتِ webhook حقيقيّةَ الصيغةِ عبرَ HTTP |

## التشغيل

```bash
./bootstrap.sh                 # مرّةً واحدة: Bun وPG وRedis وقاعدةٌ وهجرات
SMOKE=2 ./run_all.sh           # تجربةُ دخان: مشوارٌ وتوصيلٌ وقروبٌ من البدايةِ للنهاية
INTENSIVE_MIN=30 EDGE_MIN=10 ./run_all.sh
./monitor.sh                   # لقطةُ حالةٍ أثناءَ التشغيل
```

التقاريرُ في `reports/` (كلَّ 10 دقائق + `final.json`)، والسجلّاتُ في `logs/` — وكلاهما خارجَ git.

## ما يفعلُه المولّد

1. **البذر عبرَ حوارِ البوتِ نفسِه**: 5 مدن (جدة/مكة/الرياض للمشاويرِ والتوصيل، الطائف/المدينة للقروبات)،
   20 قروبًا (15 تشغيليًّا + 5 غيرُ مسجّلة)، 50 سائقًا (نقلٌ وتوصيلٌ مشتركون + غيرُ مشتركين للقروب)، 100 زبون.
2. **مرحلةٌ مكثّفة** بتوازٍ متصاعد 4→24: مشوارٌ (طلب ← عرض ← قبول ← بدء ← إنهاء ← تقييمان)، وتوصيل،
   وقروب (طلبٌ بلا مشتركٍ متاح ← نشرُ العاملِ في قروبِ المدينة ← مطالبات ← اختيار ← محادثة ← اتفاق ← رحلة).
3. **حالاتٌ حدّيّة**: سرٌّ خاطئ، JSON مشوّه، تكرارُ `update_id`، سائقانِ يقبلانِ معًا، طلبٌ ثانٍ مع نشط، سائقٌ غيرُ متاح،
   قروبٌ ممتلئ (5 مطالباتٍ على 3 مقاعد)، مطالبةٌ مكرّرة، طلباتُ انضمام، إنهاءُ كلِّ اتّصالاتِ القاعدة، وقتلُ البوّابةِ بـSIGKILL.

## حدودٌ معلنة

- المولّدُ **يقرأُ العروضَ المعلّقةَ من القاعدة** ليقبلَها؛ السائقُ الحقيقيُّ لا يراها إلا بإشعار. لذا فنِسَبُ نجاحِ
  المطابقةِ هنا **أعلى** ممّا يُتوقَّعُ في الإنتاجِ ما دامَ صندوقُ الإشعاراتِ متأخّرًا — راجع نتيجةَ الجلسةِ في
  `docs/evidence/capacity/SANDBOX-SOAK-01-20261015.md`. الخطوةُ التاليةُ: قبولٌ يُشترطُ فيه وصولُ الرسالةِ إلى المحاكي.
- `unmatched_escalate_after_seconds=20` لمدينتَي القروب في القاعدةِ التجريبيّة فقط، لتقصيرِ الانتظار.
