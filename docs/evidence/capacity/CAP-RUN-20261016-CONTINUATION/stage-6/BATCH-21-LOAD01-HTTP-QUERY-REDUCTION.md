## 4. لماذا لا يكفي الخفضُ ضمنَ الميزانية

الحجزُ لكلِّ دورةٍ مكتملةٍ مع المرشّح 1 ≈ 0.257s من زمنِ اتصال. ليبقى 750 مستخدمًا متزامنًا ضمنَ مهلةِ 20s بإشغالٍ ≤ 0.7 لخمسةِ اتصالات، يلزمُ حجزٌ ≤ 0.7×5×20/750 ≈ 0.093s للدورة — أي خفضٌ ≈ 2.8× إضافيّ. كلُّ ما وُجِدَ قابلًا للدمجِ دونَ مساسٍ بالصلاحيات (المرشّحان معًا) خفضَ الاستعلاماتِ 12.7% وزمنَ الحجزِ لكلِّ دورةٍ ≈ 5% (A 0.272s → B 0.257s). والبقيّةُ قراءاتٌ أمنيّةٌ أو كتاباتٌ (§1). وسابقةُ `gatewayRequest = 6` (ملحق ADR 0289: 250 PASS و500 FAIL على G1) تدلُّ أنَّ زيادةً صغيرةً لا تكفي أيضًا. شرطُ التوقّفِ في الدورةِ متحقّق: الاقتراحُ في [ADR 0291 (مقترح)](../../../../adr/0291-proposed-gateway-request-pool-budget-for-750.md)، ولا يُنفَّذُ قبلَ موافقةٍ مستقلّة.
