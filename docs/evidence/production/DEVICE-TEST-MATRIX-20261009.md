**الحالة:** مُعَدّة، **غيرُ منفَّذة**. لا يُسجَّلُ PRD-008 ولا PRD-101 Verified قبلَ تنفيذِها بدليل.
**النطاق:** الخطواتُ 3 و4 و11 تخصُّ R0/R1/LOST وتُختبَرُ بعدَ دمجِها ونشرِها فقط.
