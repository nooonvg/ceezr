## سلّم الحالات

لا يُمنح بند حالة أعلى مما يثبته دليله. الترتيب تصاعدي:

1. `لم يبدأ`
2. `قيد التنفيذ`
3. `نُفذ في الشيفرة`: الشيفرة مدموجة في `main`، ويُذكر رقم PR أو commit.
4. `اجتاز الاختبارات الآلية`: اختبار يمر بالمسار الحقيقي، لا بـ mock وحده، مع اسمه ونتيجة CI.
5. `نُشر في الإنتاج وتحقق منه`: الـ commit المنشور لكل خدمة متأثرة، مع أثر إنتاجي مقيس.
6. `اجتاز اختبار تيليجرام الفعلي`: على حسابات وأجهزة حقيقية، ويُرفق دليل في `docs/evidence/`.
