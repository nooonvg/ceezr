# ADR 0261: رفعُ وثائقِ السائقِ موقوفٌ حتّى تثبتَ استعادةُ ملفّاتِ Storage

**الحالة:** مقبول.
**التاريخ:** 2026-10-11
**المرجع:** `F3-01` (روابطُ الرفعِ الموقَّعة) · PRD-104 (النسخُ والاستعادة) · `docs/evidence/production/BACKUP-STORAGE-20261011.md`
**Work Packet:** `docs/work-packets/ops-pause-driver-document-uploads.json`

## السياق

- وثيقةُ السائقِ تُرفَعُ **مباشرةً إلى Storage** برابطٍ موقَّعٍ تصدرُه البوّابة (`POST /v1/driver/documents/upload-url`)، فبايتاتُها ليست في القاعدة.
- نسخُ القاعدةِ الليليُّ لا يحملُ بايتاتِ Storage، ولا نسخُ Supabase. وسجلُّ التشغيلِ الحقيقيِّ `38163083177` يقولُ: «Storage bytes not configured; database expects 0 objects» — لم يُنسَخ ملفّ.
- ومُوقِّعُ الرفعِ **مُهيَّأٌ في الإنتاج**: لا سطرَ `driver_documents.signer_not_configured` في سجلِّ البوّابةِ منذُ 2026-09-15، والسجلُّ يحملُ رسائلَ الإقلاعِ الأخرى من الدالّةِ نفسِها. فكانَ يمكنُ لسائقٍ اليومَ أن يرفعَ وثيقةً لا نسخةَ لها.
- `driver_documents` = 0 صفّ، و`storage.objects` في `driver-documents` = 0 (قراءةٌ 2026-10-11).

## القرار

1. **إذنُ الرفعِ لا يُمنَحُ إلّا إذا كانت `DRIVER_DOCUMENT_UPLOADS` = `enabled` حرفًا** في بيئةِ البوّابة. وأيُّ قيمةٍ أخرى أو غيابُها ⇐ مُوقِّعٌ غيرُ مُهيَّأ ⇐ `UPLOAD_NOT_AVAILABLE` (النصُّ القائم «الرفع غير مهيّأ في هذا الخادم.») — يفشلُ مغلقًا.
2. **شرطُ فتحِه** (يكتبُه المالكُ لا الشيفرة): تشغيلٌ ليليٌّ بـ`storage_file_bytes_included = true`، ثمَّ تمرينُ `scripts/storage-restore.sh` إلى مشروعٍ معزولٍ ناجحٌ ومُوثَّق (`ceezr-backups/docs/RESTORE.md` §6.1).
3. القراءةُ ولوحُ الحالاتِ والمراجعةُ **لا تتأثّر**؛ ولا شاشةَ ولا نصَّ جديد (تجميدُ الميزاتِ PRD-010).

## البدائل المرفوضة

- **تعطيلُ المُوقِّعِ بحذفِ مفتاحِ التخزين:** يُعطِّلُ روابطَ القراءةِ للمراجعةِ أيضًا، ويخلطُ «غيرُ مُهيَّأ» بـ«موقوفٌ عمدًا» في السجلّ.
- **فحصُ `db_backups` حيًّا عندَ كلِّ طلب:** يربطُ مسارَ السائقِ بجدولِ تشغيلٍ ويُخفي قرارَ الفتح؛ والتنبيهُ عندَ تعطّلِ النسخِ قائمٌ أصلًا (فشلُ التشغيلِ الليليّ + المراقب).

## الأثر والرجوع

- الأثر: السائقُ لا يرفعُ وثائقَه حتّى يُفتَح؛ فيبقى «قيدَ المراجعة» — وهو حكمُه أصلًا بلا وثائق.
- الرجوع: ضبطُ `DRIVER_DOCUMENT_UPLOADS=enabled` في Render ثمَّ إعادةُ تشغيلِ البوّابة، أو إعادةُ نشرِ `9519056f`.
