## 9. Priority Actions (P0 first)

1. **P0: Tracking Security** — Do NOT mount tracking routes until auth is implemented. Auth must derive driverId from a server-issued token, not client body.
2. **P0: Canonical Location ADR** — Declare `drivers.last_location` (PostGIS) as canonical. TrackingService writes to it. Redis is cache only.
3. **P0: GPS Validation Hardening** — Add Number.isFinite, lat/lng range checks, out-of-order timestamp detection, separate REJECT/WARNING/ALERT.
4. **P1: OSRM Bug Fixes** — Fix table destination index, respect profile, add timeout, handle failures.
5. **P1: Tracking Session State Machine** — CREATED → ACTIVE → STALE → ENDED with ownership checks.
6. **Document out-of-scope** — MapLibre, realtime E2E, ETA, geofencing, load testing.
